# Roadmap

- Claude Code-first README and install flow.
- Native skill folder with `SKILL.md`.
- Portable prompt generator.
- Scenario playbooks for planning, review, architecture, debugging, product, and research.
- Adapter notes for Claude Code, Codex, Cursor, Windsurf, Cline, Aider, Zed, and Copilot Chat.

## v0.3

- Add lightweight benchmark prompts for plan quality and concision.
- Add community playbooks for common stacks.
- Add release packaging for one-command installation.
